# 功能设计文档

版本：v1.0 · 日期：2026-11-14 · 本文描述待开发行为。视觉细节见 [UI 规范](03-UI-DESIGN-SYSTEM.md)，协议边界见 [同步设计](05-SYNC-AND-CREDENTIALS.md)。

## 1. 产品定位与典型流程

面向个人开发者、运维和自有服务器管理者的 Windows SSH 工作台。离线可管理本地配置与本地终端；联网后使用 SSH、SFTP、监控、隧道及可选云同步。

- 开发：启动应用 → 打开 WSL 与测试服务器 → 左右分屏 → 修改本地文件 → SFTP 上传 → 观察服务输出。
- 运维：选择生产主机 → 使用已保存身份连接 → 查看 CPU/内存 → 打开 tmux → 传输日志 → 建立数据库本地转发。
- 多设备：登录应用账号 → 解锁同步保险库 → 合并鸿蒙主机配置 → 补充本机私钥 → 连接。
- 穿透：选择自有公网中继 → 配置远程监听及本机目标 → 启动反向转发 → 显示监听状态与外部可达性验证结果。

首版只做单人账号空间，不包含团队权限管理；保存 SSH 用户不等于修改服务器 `/etc/passwd`。

## 2. F01 主机与连接资产

### 2.1 数据与操作

主机字段：稳定 ID、显示名称、地址、端口、用户名/身份引用、认证方式、凭据引用、主机指纹、分组、标签、备注、收藏、跳板链、终端配置、连接超时、keepalive、重连策略、初始命令和 tmux 选项。

支持新增、复制、编辑、删除、搜索、排序、批量移组、收藏、最近访问和快速连接。单击选中查看详情，双击或 Enter 连接；显式“新会话”可对同一主机再次连接。临时快速连接默认不入库，可另存主机。

分组首版为单层；主机可有多个本地标签。主机归组、标签、备注等新增元数据在现有同步模式下仅存本机，并显示范围标识。

导入 OpenSSH config 的受支持子集：Host、HostName、User、Port、IdentityFile、ProxyJump、ServerAliveInterval。通配、Include 和无法映射选项显示预览与诊断；ProxyCommand/Match exec 不自动执行。导出默认不含密码和私钥，敏感备份使用独立加密包。

### 2.2 异常与验收

端口非法、重复别名、跳板环路、缺失身份、私钥文件不存在均定位到字段。删除主机前展示它引用的会话与转发规则；是否断开运行会话由用户明确选择，共享身份与私钥不级联误删。

验收：5,000 条主机可搜索并虚拟化展示；编辑地址不改变已有连接的目标；保存失败不产生半条记录。

## 3. F02 SSH 连接与恢复

- 密码、带口令/无口令私钥、keyboard-interactive（含多轮 MFA）；Windows OpenSSH Agent 为首版验证项，Pageant 作为增强。
- 首连展示真实 SHA256 指纹和来源；已知指纹变化阻断自动连接，提供旧/新对照。每个跳板独立校验。
- 默认超时建议 15 秒，可调；keepalive 默认 30 秒；重连退避 1/2/5/10/20/30 秒并增加抖动，最多 10 次，均可关闭。
- 重连不重放用户输入，不自动重发上次未完成命令。网络恢复可提前触发一次重试，认证失败停止机械重试。
- 连接状态：未连接、解析地址、TCP 连接、握手、待信任、认证、就绪、重连等待、失败、关闭。阶段名称来自真实事件，禁止虚构百分比。
- 普通 SSH 重连保留旧输出作为历史，但标出新连接边界；远端进程是否继续运行不作保证。

验收：密码错误、网络黑洞、指纹变化、MFA 超时、跳板失败分别给出可操作提示；关闭窗口没有泄漏 socket 或重复重连。

## 4. F03 本地 PowerShell、CMD、WSL

提供 Windows PowerShell、已安装 PowerShell 7、CMD 与 WSL 发行版配置。自动发现已有程序；未安装的选项显示说明和系统入口，不自动安装、不代替用户启用系统功能。

本地配置包括名称、程序绝对路径、参数数组、工作目录、环境变量覆盖、字体主题和默认打开方式。CMD 使用 shell 自身编码行为，WSL 支持发行版与 Linux 用户选择；路径中含空格、中文均必须支持。

通过 ConPTY/node-pty 运行，支持 Ctrl+C、交互式程序、窗口 resize 和进程退出码。管理员启动为单独明确操作，不为应用默认提权。退出应用会结束本地会话，恢复工作区只重新启动配置，不宣称恢复原进程。

验收：同一窗口同时打开 PowerShell/CMD/两个 WSL 发行版；关闭其中一个不影响其他会话；WSL 不可用不影响远程 SSH。

## 5. F04 终端显示、输入与 Linux/tmux 兼容

### 5.1 必需能力

UTF-8、中文双宽字符、组合字符、常用 emoji、框线、256 色与真彩、替代屏幕、选区、搜索、URL、光标形态、括号粘贴、鼠标上报和 IME。提供字体回退及 Nerd Font 选项；连字默认关闭，可选开启。

默认外层终端类型 `xterm-256color`。发现远端缺 terminfo 时给出诊断和手动降级选项；不自动往服务器安装或修改环境。不强行覆盖 tmux 内层 TERM，不把 tmux 问题简单归为 Linux 发行版问题。

目标覆盖 Ubuntu/Debian、Rocky/AlmaLinux、Fedora、openSUSE、Alpine/BusyBox；Bash、Zsh、Fish、sh；vim/neovim、nano、less、top/htop、tmux 和 GNU screen。精确版本与平台组合在验收计划锁定。

### 5.2 输入规则

- Ctrl+C 保留给前台程序；默认复制 Ctrl+Shift+C、粘贴 Ctrl+Shift+V；Ctrl+Insert/Shift+Insert 可配置。
- tmux 的 Ctrl+B 和 screen 的 Ctrl+A 默认透传；应用快捷键不抢占。
- 多行粘贴默认展示预览；进入括号粘贴的程序仍使用对应协议；自动换行不能擅自变成执行。
- 不根据终端正文猜测“密码提示”并自动注入保存的密码；SSH 认证提示与 shell 内 sudo 输入分离。
- OSC 链接不自动打开，剪贴板写入请求有单独策略；终端数据不作为 HTML 执行。
- 隐藏标签继续接收有限缓冲输出，屏幕再次可见时恢复正确内容；不为省资源静默丢弃输出。

### 5.3 tmux 工作流

每主机可启用“连接后附着 tmux”，设置会话名、缺少 tmux 时的处理和连接成功后的提示。默认没有 tmux 则回普通 shell 并说明，不自动安装。

初始命令分为“首次连接执行”和“每次重连执行”，默认只首次执行。附着已有 tmux 时不向未知前台程序自动发送初始化脚本；重新执行需显式配置和确认语义。恢复布局、恢复输出与远端进程恢复在 UI 中分别描述。

验收：tmux 分屏、鼠标模式、复制模式、中文、真彩、缩放、detach/attach 和断网重连均不出现错行、残影或快捷键吞键。

## 6. F05 工作区、多标签与分屏

支持混合本地/远程标签、标签重排、固定、重命名、标签颜色、关闭其他、最近关闭列表；水平/垂直嵌套分屏、拖动分隔线、窗格最大化和键盘切焦点。首版支持最多 8 个可见窗格，默认推荐不超过 4 个；超过最小尺寸时阻止继续分割。

保存工作区包含主机/本地配置引用、窗格树、比例和工具面板，不保存明文输出、活动网络句柄或密码。恢复前列出缺失主机、凭据或本地 Shell；默认询问是否重新连接，生产环境不批量静默重连。

“关闭视图”“断开会话”“退出应用”明确区分：后台保留的会话必须能在活动会话区找到，不能隐形存在。多窗口迁移优先保持后端连接，终端前端状态恢复需要专门验证。

命令广播为首版受控能力：显式选择目标、持续显示目标数量与醒目标识、可以一键退出；默认关闭，应用重启不恢复广播。

## 7. F06 SFTP 与传输

终端内提供远程文件面板，另有完整本地/远程双栏文件页。支持路径面包屑、隐藏文件、排序、搜索当前目录、刷新、新建文件夹、重命名、删除、权限查看/修改、软链接识别及拖放上传下载。

传输队列显示文件、方向、大小、进度、速率、状态和失败原因；默认每主机最多 2 个任务并发，全局 4 个，可调。支持暂停、继续、取消、失败重试、覆盖/跳过/另存策略、目录递归与重启后任务恢复。

断点续传需校验源/目标大小、修改时间及已记录元数据，无法确认一致时提示重传；不能仅看长度就盲目追加。下载先写临时文件，完成后原子替换；上传优先临时远端文件后改名，不支持原子改名的服务器显示能力差异。

目录跟随只在有可信 shell 集成或显式“定位此路径”时生效；不能通过解析彩色提示符猜当前目录。远程编辑器列入后续版本，首版可下载后使用外部编辑器，回传需明确动作。

## 8. F07 用户、密码与密钥保存

### 8.1 身份中心

身份记录包含名称、用户名、认证方式和凭据引用，可供多台主机复用。保存用户名、保存密码、保存私钥、保存私钥口令是独立选择；仅记住用户名时，每次连接仍可询问密码。

支持私钥导入、Ed25519/RSA 生成、公钥复制、指纹查看、口令保护与凭据替换。默认只导出公钥；私钥导出需主动操作及解锁，不在普通配置导出中混入。证书/FIDO2 为后续增强。

已有主机可选择共享身份或本机单独覆盖；更新共享身份时显示影响范围，不自动改写已经建立的 SSH 会话。

### 8.2 应用用户

支持账号注册/登录、记住账号、保持登录、退出、设备列表与撤销设备。保持登录保存受系统保护的 refresh token，不保存应用登录密码作为自动登录材料。切换账号先停止旧账号同步；不同账号的缓存与待上传修改隔离。

本地数据导入账号空间前展示合并预览。退出应用账号与删除本地 SSH 凭据是不同操作，不相互隐式触发。

## 9. F08 云同步

首版必须实现现有协议的主机基础字段、分组对象、L/R/D 转发双向同步，以及用户自选密码/口令同步。私钥在本地必须能保存；跨端私钥同步显示能力限制，直到鸿蒙缺口修复并完成往返验证才开放为“完整互通”。

用户可离线编辑；恢复网络后进行 base/local/remote 三方合并。冲突展示字段来源与修改对象，敏感值遮盖，删除冲突不自动覆盖。同步结果显示成功时间、待上传数、冲突数和当前范围。

主题、窗口、Shell 路径、快捷键、标签、主机归组、完整身份模板等暂为本机项。未来扩展不得向当前严格 schema 添加未知字段。协议升级属于独立跨端工作，不假设服务端能存密文就等于旧客户端能理解新文档。

验收：鸿蒙创建主机后 Windows 拉取；Windows 改地址后鸿蒙拉取；离线双端修改不会静默覆盖；关闭敏感同步完成轮换与云历史处理后才显示完成。

## 10. F09 服务器监控

### 10.1 指标与呈现

默认提供 CPU 总使用率、内存已用/可用/总量、Swap、1/5/15 分钟负载、启动时长、磁盘容量、网卡收发速率。详情面板可查看核心、挂载点、网卡与进程 Top 列表。CPU 百分比与 load average 不混用；内存采用明确的 available 口径。

首次有效采样前显示“采集中”，缺权限显示“无权限”，过期显示“数据已过期”及时间；不使用 0 代替未知。容器内数据标出作用域与限制，不能冒充宿主机完整监控。

### 10.2 行为与边界

优先无 Agent、普通权限、只读采集。使用独立 exec/监控通道，不向用户 shell 插入命令；同主机同身份的多个视图共享采集器。指标面板跟随聚焦主机，也可固定，固定时持续显示主机名称。

前台 CPU/内存/网络默认 2 秒，磁盘 15 秒，进程列表 5 秒且仅展开时采集；后台降为 10 秒或暂停，最小化可暂停图表但保留会话。失败超时不堆积任务、不频繁重连 SSH。

Ping、SSH 往返和业务响应耗时分开命名。首版基础状态显示 SSH 探测耗时，不能伪称 ICMP 延迟；Ping/路由跟踪为可选诊断，远端不具备权限时降级。

## 11. F10 端口转发与穿透

- **本地转发 L**：本机监听 → SSH → 目标主机可达服务。例如本机 15432 访问远端数据库 5432。
- **远程转发 R**：SSH 中继监听 → SSH → Windows 客户端可达目标。例如中继 18080 转到本机 127.0.0.1:3000。
- **动态转发 D**：本机 SOCKS5 监听 → SSH → 按请求访问目标；首版 TCP CONNECT，不承诺 UDP ASSOCIATE。
- **跳板链**：通过一个或多个 SSH 主机连接目标；首版最多 3 跳，检测循环，每跳独立认证与主机校验。

规则字段包括名称、类型、SSH 主机、监听地址/端口、目标地址/端口、重连策略、分组及本机自动启动偏好。默认监听 127.0.0.1；改为 0.0.0.0 或 :: 时明确展示暴露范围，用户选择后才绑定。

公网 R 转发依赖可达中继、AllowTcpForwarding、GatewayPorts、PermitListen/PermitOpen 及防火墙等。UI 区分“SSH 已连接”“远端监听申请成功”“外部可达性未验证”；仅创建监听不能直接显示公网穿透成功。

展示活跃连接数、双向字节数、监听状态、错误及重连记录。关闭终端标签时若隧道仍在运行，应保留后台并可在隧道中心管理。配置同步不自动开启另一设备的端口，避免绑定冲突和意外暴露。

首版不提供托管公网中继、不安装 frp、不修改服务端配置；frp 与 HTTP 域名隧道为后续扩展。

## 12. F11 命令片段与效率工具

片段按名称/标签搜索，支持明确命名的变量与执行前预览；“插入输入区”和“执行”分开。初始命令按 F04 策略处理，广播执行需显示所有目标。命令历史默认只记用户确认的普通命令；无法可靠判断的敏感输入不自动采集，日志与历史均可关闭与清除。

全局命令面板可搜索主机、工作区、片段和设置；快捷键可改，有冲突检测。Ctrl+K 默认仅用于非终端焦点区域；终端内保留 shell 的 Ctrl+K。

## 13. F12 外观、3D、开屏与设置

深色默认，支持终端独立主题、字体、字号、行高、光标、背景透明度、壁纸和高对比度；UI 主题与终端 ANSI 配色分开。

开屏包含原创 3D 连接核心，连接态有局部 3D 反馈；默认自动按图形能力、设备资源与持续帧率选择完整/轻量/关闭，也允许手动轻量、关闭或强制完整。自动模式响应系统减少动态效果；强制完整由用户明确覆盖此偏好。GPU 不可用或上下文丢失时自动切静态视觉，所有业务仍可使用。

设置包括启动页、关闭窗口行为、托盘、会话恢复、终端快捷键、性能档、监控频率、日志保留、代理、同步范围及凭据锁定。锁屏默认锁定应用访问并停止新凭据解密；已建立 SSH/隧道是否继续由明确策略控制。

## 14. F13 安装、更新与数据维护

首发 Windows x64 安装包；签名、更新通道、卸载保留数据策略在发布阶段落实。更新前提示活跃会话与传输，不强制重启。数据库迁移前备份、失败可恢复；用户可导出不含敏感值的诊断包。

安装包、便携模式和跨机器备份不能混为一谈：系统保护的密文通常绑定当前 Windows 用户，迁移必须使用用户口令加密的专门备份格式。

## 15. 首版完成标准

F01–F13 的核心流程全部具备真实后端与异常反馈，没有示例路径或假数据代替业务；class 规范和兼容性矩阵通过检查。私钥完整跨鸿蒙互通、主机归属同步等协议升级项必须明确标为依赖项，不能与本地保存及基础同步混淆。
