# UI、风格与前端命名规范

版本：v1.0 · 日期：2026-11-14。所有尺寸为设计起点，单位为 CSS px；必须在真实 Windows DPI、字体和终端负载下验证。

## 1. 设计方向：Graphite Orbit

暂定风格名「Graphite Orbit／石墨轨道」，不作为正式产品品牌。石墨底色、少量紫青高光、清晰信息层级、柔和空间感。主工作区沉稳，开屏与连接等待表现 3D 特征。

终端文本为第一视觉优先级；监控、连接状态、文件操作为第二层；装饰为第三层。禁用常驻全屏粒子、终端正文霓虹阴影和输入时的缩放抖动。

借鉴依据见 [参考分析](01-REFERENCE-ANALYSIS.md)。本文件的配色、布局与动效参数为原创规划，不是对竞品现状的描述。

## 2. 设计变量

### 2.1 颜色

- `--color-app-bg: #0B0D12`：主背景。
- `--color-surface-1: #12151D`：导航、侧栏。
- `--color-surface-2: #191D28`：弹层、悬浮。
- `--color-terminal-bg: #0D1016`：默认终端背景，允许被终端主题覆盖。
- `--color-border: #2A3040`：结构分隔。
- `--color-text-primary: #E8ECF4`；次要文字 `#A5AFC2`；辅助文字 `#7F8BA3`。
- `--color-accent-primary: #A78BFA`：主要操作、选中、焦点；按钮文字默认深色 `#151021`。
- `--color-accent-secondary: #5BDCF4`：连接与路径反馈。
- 成功 `#59D6A0`、警告 `#F5C46B`、错误 `#FF7D93`；必须同时使用文字或图标表达状态。

高光面积建议低于界面 10%。微弱渐变与光晕仅用于品牌、选中细节和 3D 舞台；不能覆盖正文。上述色值不是已完成的对比度认证，验收需实测正常文本至少 4.5:1、关键非文本控件边界至少 3:1。

### 2.2 字体、尺寸与层次

UI 默认 `Segoe UI Variable / Segoe UI / Microsoft YaHei UI / sans-serif`，常规 13px，正文 14px，辅助 12px，页面标题 20px。终端默认 JetBrains Mono + Sarasa Term SC 回退，14px，行高初始 1.2；附带字体必须保留许可证。用户可选择系统等宽字体或 Nerd Font。

间距档：4/8/12/16/24/32。圆角：小控件 6、卡片 10、弹层 14。标准控件高 32，舒适模式 36；列表行紧凑 32、舒适 40。拖动分隔线可见宽 1，命中区 6–8。图标统一线性风格 16/18/20px，不混用 emoji 作为核心操作图标。

CSS 层级集中定义：基础 0、粘性标题 10、浮动工具 20、下拉 100、抽屉 200、模态遮罩 300、模态内容 310、通知 400、开屏 500。Tooltip 不允许遮挡认证输入和系统窗口按钮。

### 2.3 样式组织

SCSS 负责模块组织、mixin 与可复用样式片段；CSS 自定义属性负责运行时颜色、字号、密度和动效档。样式通过变量改主题，不运行时生成巨量选择器。

组件样式默认 scoped，公共设计变量在全局根节点注入。避免深层 DOM 选择器和大量 `!important`；禁止依赖 `nth-child` 确认业务元素。不开启会改变可读业务类名的 CSS Modules 哈希作为主命名策略。

## 3. class 命名：强制规范

### 3.1 固定格式

每个自有实际 DOM 元素必须有符合以下格式的语义 class：

```text
container_页面名_功能名_位置名_扩展名
```

Vue 模板使用 `class` / `:class`，不写 JSX 的 `className`。四个字段均不可省略；固定前缀 `container` 不表示元素必须是 div，button、span、input、canvas、svg 等同样遵守。

字段使用小写英文与短横线，同一字段内不用下划线，以保证五段可解析：

```text
^container_[a-z][a-z0-9-]*_[a-z][a-z0-9-]*_[a-z][a-z0-9-]*_[a-z][a-z0-9-]*$
```

- 页面名：稳定的页面/模块别名，如 `workspace`、`hosts`，不能采用用户名或主机地址。
- 功能名：`terminal`、`hostlist`、`monitor`、`transfer` 等明确功能。
- 位置名：语义位置，如 `root`、`header`、`toolbar`、`body`、`footer`、`sidebar`、`overlay`、`dialog`、`row`。不绑定会频繁变化的绝对坐标。
- 扩展名：具体元素角色，如 `title`、`connect-button`、`cpu-value`、`surface`；无细分时用 `base`，禁止空段。

### 3.2 唯一性的两层含义

**语义唯一**：不同模板位置不得复用同一语义类，例如保存按钮与取消按钮必须不同。一个语义类只对应一个组件文件里的一个角色。

**实例唯一**：v-for、同组件多次出现、多窗格和多窗口时，保留语义类用于样式，同时添加唯一实例类。实例后缀附在第五段，不增加下划线段数：

```text
container_workspace_terminal_body_surface
container_workspace_terminal_body_surface-iw1-p7
```

其中 `iw1-p7` 为内部稳定的窗口/窗格标识。它不含 IP、用户名、密码、真实路径；排序与重绘不改变标识，新增实例使用不会碰撞的内部 ID，不能仅用数组索引或当前时间。

所有重复行里的子节点也增加实例类，而不是只给列表最外层增加。唯一性以整个应用运行实例为目标，标识包含 windowId；检查可以逐窗口扫描并汇总注册表。

实例类用于定位，不为每个实例生成 SCSS 规则。`data-host-id`、`data-session-id`、`data-testid` 可附加用于逻辑与测试，但不能替代要求的语义/实例 class。

### 3.3 模板示例

以下是文档示例，不是已创建的应用代码；示例假定一个工作台标题栏：

```vue
<header class="container_workspace_session_header_base">
  <span class="container_workspace_session_header_title">会话</span>
  <button
    class="container_workspace_session_header_connect-button"
    type="button"
    aria-label="新建连接"
  >
    <span class="container_workspace_session_header_connect-label">新建连接</span>
  </button>
</header>
```

重复实例示例：

```vue
<div
  v-for="pane in panes"
  :key="pane.id"
  :class="[
    'container_workspace_terminal_body_surface',
    `container_workspace_terminal_body_surface-i${windowToken}-${pane.token}`
  ]"
  :data-session-id="pane.sessionId"
  :data-active="pane.id === focusedPaneId"
/>
```

`windowToken` 与 `pane.token` 必须由统一安全 token 工具生成，仅含小写字母、数字、短横线。不得把未经规范化的业务字符串拼进 class。

### 3.4 状态、组件与例外

- hover/focus/disabled 优先使用伪类和 ARIA/data 属性，避免额外的 `.active`、`.selected`、`.error` 等不符合规则的 class。
- 若确需状态 class，仍用完整五段，例如 `container_hosts_connection_row_error`，保留原始语义类。
- 共享组件使用 `shared` 页面命名空间，内部元素采用自身功能名，并通过实例 token 保证多实例可定位；页面包装元素使用实际页面名。Vue 多根组件须显式分发 class，不能依赖隐式属性继承。
- Teleport 弹层保留来源页面命名，唯一 token 带 ownerWindowId，不通过 DOM 父节点推断归属。
- Vue 的 template/slot、纯文本节点与伪元素不是真实独立 DOM，无 class 要求；自写 SVG 的实际节点同样命名。
- **第三方生成内部 DOM**（xterm、图表库、第三方图标组件等）不强行重命名。必须有合规的自有包装层，并在 `style-exceptions` 清单登记库、范围和原因；仅允许受控适配文件覆盖必要样式。
- 不使用 MutationObserver 给第三方每个节点补随机类；这会增加终端负担并破坏内部行为。

### 3.5 自动检查要求

开发阶段增加 Vue template AST 规则：检查自有元素是否带合规语义类，识别静态/动态 class、v-for 和共享组件实例。Stylelint 校验自有样式选择器格式；SCSS `&` 展开后再审查结果。

构建输出语义类注册表（类名、组件文件、位置、是否重复实例），检查跨组件意外复用。Playwright 在主机列表、分屏、弹层、登录等代表状态检查实例唯一性。第三方例外必须显式登记，不能大范围关闭检查。

目标：自有 DOM 合规覆盖率 100%；已知第三方内部节点单独报告，不伪造为 100% 全 DOM 改造。

## 4. 页面命名与信息架构

- `app`：窗口壳、标题栏、全局状态与通知。
- `splash`：开屏舞台、启动阶段、跳过入口。
- `workspace`：标签、分屏、终端工具栏、连接反馈。
- `hosts`：主机、分组、快速连接、主机编辑。
- `local`：Shell 配置与 WSL 发行版。
- `sftp`：文件浏览、路径、文件操作。
- `transfers`：传输任务与历史。
- `monitor`：指标、趋势、进程与诊断。
- `tunnels`：转发、穿透、跳板诊断。
- `identities`：用户名、认证模板与引用关系。
- `keychain`：密码、私钥、口令和锁定。
- `snippets`：片段、变量预览与广播。
- `account`：登录、设备、账号资料。
- `sync`：范围、状态、冲突、版本历史。
- `settings`：外观、快捷键、性能与偏好。
- `shared`：跨页面公共控件。

主导航显示“工作台、主机、本地终端、隧道、身份与密钥、片段”，设置与账号置底。SFTP、监控、传输同时有上下文入口，不强迫离开终端。

## 5. 桌面布局

### 5.1 默认工作台

以 1440×900 为主要设计画布。顶部自定义标题栏 40，标签栏 36；左导航 56，主机栏 240（可调 200–360）；右指标栏 280（可调 240–360）；底部状态栏 24。中间终端获得剩余空间。

底部 SFTP/传输/片段面板默认收起；展开初始高 240，可调但须保留终端最小工作高度。工具栏与上下文按钮在相应区域，不用多个浮动按钮遮住终端。

窗口标题栏保留正常拖动、最大化与系统布局行为；交互按钮设置不可拖动区域。图表、终端、输入框不能被标题栏拖动命中覆盖。

### 5.2 尺寸变化

- 宽 ≥1440：允许主机栏 + 终端 + 监控栏三列并存。
- 1180–1439：默认收起监控栏，用户可展开并自动收窄或折叠主机栏。
- 960–1179：辅助工具转抽屉/底部面板，优先保留终端。
- 建议最小窗口 960×640；仍需验证高 DPI 后可用 CSS 尺寸，不把物理像素当 CSS 像素。
- 单窗格最小建议 320×180；分屏不足时拒绝新增并说明，可切换标签或最大化当前窗格，不自动销毁会话。

125%/150%/200% DPI、跨显示器拖动、最大化/还原、字体切换后重新测量并更新 PTY 行列；禁止用 CSS scale 放大终端来替代真正 resize。

## 6. 关键页面与交互规格

### 6.1 主机页

顶部搜索与新增，左侧分组，主体默认紧凑列表，可切卡片。行包含别名、地址、用户名、状态、标签与更多菜单。悬浮显示快捷连接按钮；双击连接；右键包含新会话、编辑、复制、SFTP、转发和删除。主机详情采用侧面板，配置按连接/认证/终端/跳板/转发分组，避免超长平铺表单。

### 6.2 会话工作区

标签含主机/Shell 图标、名称和状态，活动标签以底色与细高光共同指示。拖动显示实际落点区域和轻量预览；松手后调整布局，底层会话不重连。空白区提供“连接主机、打开本地终端、恢复工作区”。

每个窗格顶部显示主机与用户、重连/搜索/文件/更多；聚焦窗格用 1px 描边。生产环境可设文字徽标，但不把整个终端染红。切换与动画期间持续保留键盘焦点；弹层退出后返回触发前的终端。

### 6.3 监控栏

顶部固定展示主机、作用域、采样时间、刷新/暂停。CPU 与内存为数值+短趋势，磁盘/网络展开详情；每条图有单位。图线不做平滑造假，不在无数据时生成随机趋势。颜色异常必须有明确阈值和文字。

### 6.4 SFTP 与传输

文件面板顶部路径与常用操作，中部列表，底部选择统计。上传拖入时高亮目标目录并显示“将上传到”；进入终端正文时则提供“上传文件 / 插入路径”选择，不能默默执行本地路径。

冲突弹窗列出源/目标大小与时间，批量策略明确作用范围。传输进度用真实字节数；未知总量显示已传输量，不画假百分比。

### 6.5 隧道与穿透

新建向导按类型选择、SSH 入口、监听端点、目标端点、验证五步组织。用带文字的方向示意辅助理解；监听地址和目标所在机器必须写清楚。公网地址只在用户请求并通过检测时确认可用，未检测用“未验证”。

### 6.6 身份、密钥、账号与同步

身份列表展示用户名、认证类型、关联主机数；密码只显示保存状态。密钥展示类型、公钥指纹、是否有口令。账号页面的“记住账号”“保持登录”“解锁同步保险库”分别表达。

同步中心列出每类数据的本地/云端状态，主机归组与私钥互通限制可见；冲突对照不显示明文秘密。用户关闭敏感同步时展示处理阶段，完成前不能显示已清除云端历史。

## 7. 3D 与开屏分镜

### 7.1 原创视觉元素

以八面古剑、层叠剑阵、水墨远山、酒葫芦和陶质酒盏表现“青冥剑境 · 万剑归宗”。玄墨为底，鎏金用于剑格与阵纹，青玉用于剑光，朱砂用于剑穗，酒琥珀用于酒液与暖光。装饰不得侵入终端正文或认证输入。

首页核心 3D 使用 Three.js 0.187.0，按需加载。完整档以 144 把实例化飞剑、近景飞剑、动态尾迹和 20 秒确定性周期表现“现身—成阵—归宗—散开”；轻量档 32 把。主剑、葫芦与酒盏使用程序化低模，不依赖远程模型。一把独立 DOM/CSS 3D 飞剑沿首页内框闭环巡航，不另建 WebGL 场景。窄窗口将操作区移到场景下方，任何装饰不得阻断新建主机与本地终端操作。

普通面板用 CSS transform 做轻微深度。终端正文不参与透视变形；无需为每个卡片创建 WebGL 场景。

### 7.2 开屏

- 0–180ms：立即显示匹配主界面的静态底与标识，避免白闪。
- 180–650ms：轨道展开，核心轻转；实际启动阶段文字为“读取配置/打开本地数据/恢复布局”等。
- 650–1,000ms：轻量光带收束，工作台淡入。主界面提前就绪则提前结束，不设置人为最短等待。
- 启动未完成时，1,200ms 后停止重复 3D，转安静状态提示；长任务显示真实原因与可重试入口。
- 鼠标点击或 Esc 可跳过动画，不能跳过实际数据迁移与必要解锁。

默认每次进程冷启动最多播放一次，可设置仅首次/每次/关闭。减少动态效果模式显示静态品牌页。开屏结束释放场景、纹理、事件和 requestAnimationFrame。

### 7.3 连接动画

仅当前正在操作的窗格显示简化核心，阶段对应 TCP/握手/认证。慢连接提供取消；等待指纹或密码时停止抢眼运动，把输入区放在主层级。连接就绪后约 180ms 淡出，输入立即可达。

重连仅使用状态条与倒计时；批量连接不同时播放多个重型 3D。应用任意时刻最多一个重型品牌场景；终端自身 WebGL 渲染不计品牌场景，但共享 GPU 预算。

### 7.4 动效与性能档

微反馈 100–140ms、状态/标签 160ms、面板 200–220ms、复杂转场上限 280ms。优先 opacity/transform；不动画终端字号、模糊半径或频繁触发全窗口布局。

完整档：首页 144 把实例飞剑、16 条动态尾迹、边框巡航、局部连接反馈与短过渡。轻量档：32 把飞剑、省略尾迹、降低像素比并延长边框巡航周期。关闭档及系统减少动态效果：静态品牌剑图、无边框巡航与瞬时状态切换。WebGL 不可用时同样降级，不影响业务操作。

持续剑境只允许出现在无终端会话的首页；进入终端后释放首页场景。页面隐藏、组件 inactive、连接等待认证或暂停时停止 RAF；卸载时释放几何体、材质、纹理和 renderer。首页完整档像素比上限 1.6，轻量档 1.2。不得为了视觉演出增加人为启动等待或延迟业务点击。

## 8. 状态与无障碍

每个页面必须设计空、加载、正常、失败、权限不足、离线与局部不可用状态；新增/保存过程中禁重复提交，失败保留草稿。局部监控失败不盖住整页终端。

统一焦点环，菜单可键盘导航，图标按钮有 aria-label，表单错误与字段关联。终端提供可用的无障碍模式入口；高对比度下取消透明背景。系统减少动态效果优先于完整动画档。

快捷键默认：Ctrl+Shift+P 命令面板、Ctrl+Shift+T 新会话、Ctrl+Shift+W 关闭当前视图、Ctrl+Tab 切标签、Ctrl+Shift+C/V 复制粘贴、Ctrl+Shift+F 搜索输出。冲突检测以本地 Shell/SSH/tmux 上下文测试为准。

## 9. UI 验收

检查 class 覆盖与实例唯一、键盘操作、焦点恢复、DPI、字符网格、滚动、拖动分屏、启动白闪、动效降级与资源释放。除静态截图外，必须在真实 SSH 输出、传输与监控并发时验证；演示数据不能用于宣告业务完成。
