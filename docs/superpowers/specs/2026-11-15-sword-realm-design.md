# 青冥剑境 · 万剑归宗设计

日期：2026-11-15。状态：用户已确认设计并授权实施。

## 目标

将首页从居中的 Canvas 2D 小组件升级为全区域、可降级的真实 3D 剑境，同时保留 SSH 与本地终端工作台的清晰操作。核心视觉是群剑汇聚而非无序粒子，主题由玄墨、鎏金、青玉、朱砂和酒琥珀构成。

## 页面构图

首页内容区使用完整可用宽度和高度。主剑与立体剑阵位于中央偏右，标题、说明和两个既有操作按钮位于左侧安全区。前景左下放置带系绳、塞子和“酒”字印的酒葫芦，右下放置带酒面和涟漪的陶质酒盏。背景使用 CSS 水墨远山、云海和暗角，WebGL 负责剑、葫芦、酒盏、阵环及光尘。

一把银金飞剑沿首页内框的圆角矩形路径持续巡航。它仅在无终端标签的首页出现，不包围整个 Windows 窗口，不进入终端输入区域。

## 剑阵叙事

每轮 20 秒，所有周期函数在首尾返回相同状态：

- 0–8 秒：远景群剑缓慢穿行，主剑悬浮，阵环旋转。
- 8–13 秒：多层螺旋轨道收紧，飞剑向主剑后方汇聚。
- 13–15 秒：主剑与阵环产生短促金色脉冲，形成“万剑归宗”高潮。
- 15–20 秒：飞剑重新散开，剑气和光尘恢复平静。

完整档使用 144 把实例化飞剑，轻量档使用 32 把。近景轨迹、深度缩放、金属明暗和少量尾迹建立数量与空间感。鼠标仅改变轻微相机视差；按钮悬停增强剑势，但不延迟任何业务动作。

## 组件边界

- `OrbitStage3D.vue`：保留现有 `welcome | compact`、`state`、`active`、`paused`、`boost`、`instance` API；负责按需加载、DOM 生命周期、主题读取和静态降级。
- `sword-scene.ts`：唯一 Three.js 场景所有者；负责模型、灯光、实例、渲染和 GPU 资源释放。
- `sword-motion.ts`：不依赖 DOM 的确定性周期运动与数量档，供场景和单元测试共用。
- `BorderFlyingSword.vue`：使用一个 DOM 飞剑、CSS 3D 和动态 `offset-path` 完成边框巡航。
- `border-flight.ts`：生成有界圆角矩形 SVG path 字符串，处理尺寸和圆角约束。
- `WorkspacePage.vue`：首页布局、背景层、操作区和边框组件。
- `_tokens.scss`、`ui-themes.ts`、`global.scss`、`NavRail.vue`：共享材质色、表面层次和克制的微反馈。

## 状态与降级

`full` 使用完整剑阵，`light` 降低实例数、像素比并省略尾迹，`off` 与系统 `prefers-reduced-motion` 显示静态品牌剑图。WebGL 创建失败同样显示静态图，不影响按钮。页面隐藏、组件 inactive 或 paused 时停止动画；卸载时取消 RAF、observer 和监听器，并释放 geometry、material、texture 与 renderer。

紧凑连接场景保留既有状态颜色，不显示酒葫芦与酒盏；等待认证时停止运动。任意时刻最多一个重型品牌场景，终端正文不做透视变形。

## 验收

边框飞剑运动连续、朝向切线且窗口缩放后仍贴合边框。首页可辨认主剑、群剑汇聚、葫芦、酒盏和涟漪，所有既有操作立即可用。五行及自定义主题同步影响 3D 材质与剑光。完成类型、格式、单元、构建和桌面 E2E 检查，并在真实 Electron 中检查首页、缩放、动效档、页面切换和终端操作。

## 假设

“万剑”通过 144 把实例剑、尾迹和景深表现，不创建一万个独立对象。首页常驻氛围与周期性高潮分离；进入终端后保持安静。保留用户现有未提交改动，提交只包含本功能路径及依赖清单中属于 Three.js 的片段。
